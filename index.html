Application Document Renamer

For any supported file beginning with an 8-digit date, the date is moved to the end. The document name is placed first, followed by any recognised additional text/code.
Examples: 20260202_1703P160DIV1 Abstract.pdf → Abstract_1703P160DIV1_20260202.pdf
20260202_1703P160SGDIV1_EN_Allowed JP Claims.pdf.unp → Allowed JP Claims_EN_1703P160SGDIV1_20260202.pdf.unp
20260202_PF8_FormDetails.pdf.unp → PF8_FormDetails_20260202.pdf.unp
PF... and PT... names remain together as the document name. If no recognised structure is found, everything after the leading date is preserved and the date is simply appended at the end.
Accepts both .pdf and .pdf.unp files and preserves the original extension when renaming. Files are processed locally in your browser.
