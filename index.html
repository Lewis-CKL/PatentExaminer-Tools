Patent Examiner Tools V2.1

Browser-based utilities for prior-art organisation, application-document housekeeping, and examiner workflows.

Prior Art Renamer

Example: Cited Documents (1. CN105630914A.pdf) → D1-CN105630914A.pdf
Files are processed locally in your browser. No PDF upload is required.

Application Document Renamer

Reorders application-document filenames from DATE_REFERENCE Document Name.pdf to Document Name_REFERENCE_DATE.pdf.
Example: 20260202_1703P160DIV1 Abstract.pdf → Abstract_1703P160DIV1_20260202.pdf
The document name may contain multiple words. Files are processed locally in your browser.

Translation

Uses the same EPO Patent Translate job flow as the supplied PowerShell application: start an EPO translation job, poll it to completion, retrieve the EPO translated PDF sections, and download the result as D#-[publication]-EN.pdf.
The GitHub Pages site is only the front end. The EPO translation relay must be running at this URL.
